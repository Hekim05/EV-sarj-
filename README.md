# EV Şarj

Elektrikli araç sahipleri için ev şarjı, maliyet, menzil ve sürüş analizi uygulaması (PWA).

- Uygulama: https://hekim05.github.io/EV-sarj-/
- Araç ve ev şarj hattı Ayarlar'dan tanımlanır; veriler yalnızca kullanıcının cihazında (tarayıcıda) saklanır.
- Tesla sahipleri için isteğe bağlı Tessie bağlantısı: Ayarlar → Gelişmiş.
